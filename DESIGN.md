# Open SourcED interface brief

Open SourcED keeps the warm, editorial card language of the original RoadReady project while broadening it into a reusable learning workspace.

## Product principles

- **Local first:** creation, studying, testing, and proficiency never require an account.
- **Sources before synthesis:** AI starts from user-provided material rather than open-ended recall.
- **Review before save:** generated cards always enter the normal editor as a draft.
- **One obvious next action:** each study surface focuses on recall rather than configuration.
- **Visible learning:** mastery represents card-level practice, not time spent in the app.

## Visual system

- Warm cream canvas and paper cards for a calm, tactile feeling
- Deep teal for trust and learning state
- Poppy coral for primary actions and energy
- Fraunces display type paired with compact DM Sans interface type
- Hairline borders, modest depth, and restrained motion
- Subject color carried through set covers, progress bars, and mastery views

## Key states

- Starter, populated, searched, and empty libraries
- New, edited, duplicated, imported, and AI-drafted sets
- Front/back flashcard states
- Revealed adaptive answer with missed/knew confidence input
- Active, incomplete, submitted, and reviewed mock tests
- Unconfigured, loading, error, and successful AI generation
- Desktop, tablet, and narrow mobile layouts

## Accessibility

All primary actions use native buttons and labels, interactive controls have visible focus states, color is paired with text or icon meaning, and layouts reflow without horizontal scrolling at phone widths.
